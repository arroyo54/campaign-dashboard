# Criterios para Aprovechar, Reformar o Crear

**Agente 0 — Director General de Investigación**
**Fase 1 · Entregable 6 de 13**

> Este es el documento operativamente más importante del proyecto. Traduce el principio
> "México no comienza desde cero" en un procedimiento que cada agente debe seguir **antes**
> de recomendar cualquier cosa.

---

## 1. La jerarquía de intervención (orden obligatorio)

Ante cualquier problema, el agente debe recorrer estas opciones **en orden** y quedarse en
la primera que sea viable. Solo puede bajar de escalón si documenta por qué el anterior no
funciona.

| Escalón | Intervención | Pregunta que la habilita |
|---------|-------------|--------------------------|
| 1 | **Aprovechar mejor lo existente** | ¿Hay capacidad instalada ociosa o subutilizada? |
| 2 | **Corregir lo parcial** | ¿Existe algo que funciona a medias y puede arreglarse? |
| 3 | **Integrar** | ¿Hay sistemas separados que juntos resolverían el problema? |
| 4 | **Escalar** | ¿Hay un programa que ya produce resultados y puede crecer? |
| 5 | **Redistribuir recursos** | ¿El recurso existe pero está mal asignado? |
| 6 | **Cambiar reglas e incentivos** | ¿El problema es de incentivos, no de capacidad? |
| 7 | **Crear capacidad complementaria** | ¿Falta una pieza que no puede obtenerse arriba? |
| 8 | **Construir nuevo** | ¿No existe nada aprovechable y es imprescindible? |

**Cuota verificable:** ≥ 70 % de las acciones de los primeros 4 años deben ubicarse en los
escalones 1–5 (o 6 cuando no implique nueva estructura). Los escalones 7–8 son minoritarios.

## 2. Árbol de decisión (aplicable a cualquier activo o problema)

```
¿Existe una capacidad que atienda este problema?
│
├── NO  → ¿Es imprescindible para el sistema?
│         ├── NO  → No crear. Registrar como "no prioritario".
│         └── SÍ  → Ir al Cuestionario de Creación (§4). [Escalón 7–8]
│
└── SÍ  → ¿Cumple su función?
          ├── SÍ, bien   → ¿Tiene cobertura suficiente?
          │                 ├── SÍ → Aprovechar / mantener. [Escalón 1]
          │                 └── NO → Escalar. [Escalón 4]
          │
          ├── PARCIAL    → ¿La falla es de operación, de reglas o de recursos?
          │                 ├── Operación → Profesionalizar / auditar. [Escalón 2]
          │                 ├── Reglas    → Cambiar incentivos. [Escalón 6]
          │                 ├── Recursos  → Redistribuir / financiar. [Escalón 5]
          │                 └── Aislamiento → Integrar. [Escalón 3]
          │
          └── NO cumple  → ¿Por qué? (capturado / obsoleto / duplicado / sin evaluación)
                            ├── Capturado    → Reformar gobernanza; si imposible, sustituir.
                            ├── Duplicado    → Fusionar. [Escalón 3]
                            ├── Obsoleto     → Sustituir (con justificación §4).
                            └── Sin evaluar  → Evaluar ANTES de decidir. No actuar a ciegas.
```

---

## 3. Regla de "evaluar antes de actuar"

Ningún activo clasificado como `SIN-EVALUACIÓN` puede ser reformado, fusionado, sustituido
o cerrado hasta que se le practique una evaluación mínima (los 16 atributos del Manual §7).
Actuar sobre lo que no se ha medido es una violación metodológica.

---

## 4. Cuestionario obligatorio para crear una nueva estructura

Toda propuesta de crear (institución, federación, liga, academia, plataforma,
certificación, universidad, competencia, infraestructura, CAR, fondo, consejo, organismo,
programa escolar, sistema de scouting) **debe** responder las 14 preguntas. Una propuesta
de creación sin este cuestionario completo se rechaza en la Puerta de Control 4.

1. ¿Qué capacidad existe actualmente?
2. ¿Quién la controla?
3. ¿Por qué no cumple su función?
4. ¿Por qué no puede reformarse?
5. ¿Cuánto costaría reformarla?
6. ¿Cuánto costaría sustituirla?
7. ¿Qué funciones asumiría la nueva estructura?
8. ¿Qué institución dejaría de cumplir esas funciones?
9. ¿Cómo se evitaría la duplicidad?
10. ¿Cómo se financiaría **permanentemente**?
11. ¿Cómo se evaluaría?
12. ¿Quién la supervisaría?
13. ¿Bajo qué condiciones podría cerrarse?
14. ¿Qué riesgo tendría de ser capturada por intereses particulares?

## 5. Prueba de "costo comparado"

Antes de sustituir o crear, es obligatorio comparar explícitamente:

| Opción | Costo de inversión | Costo de operación anual | Tiempo a resultados | Riesgo de captura |
|--------|--------------------|--------------------------|---------------------|-------------------|
| Reformar lo existente | | | | |
| Integrar / fusionar | | | | |
| Crear nuevo | | | | |

Si "reformar" o "integrar" no son estrictamente peores en el balance, se prefieren sobre
"crear". La carga de la prueba recae siempre en quien propone crear.

---

## 6. Lista de verificación anti-"lugares comunes"

Cuando un agente proponga cualquiera de estas medidas, debe adjuntar la evidencia
sistémica que la justifica (no basta la intuición):

- Limitar extranjeros · restaurar ascenso/descenso · eliminar torneos cortos · cambiar al
  DT · minutos a jóvenes por decreto · una gran academia · una nueva ley · copiar
  España/EE. UU./Argentina · más partidos en Europa · "cambiar la mentalidad" · más dinero ·
  más canchas.

Cada una se evalúa por su efecto **en el sistema completo**, con sus efectos secundarios y
sus condiciones previas, no como bala de plata.
