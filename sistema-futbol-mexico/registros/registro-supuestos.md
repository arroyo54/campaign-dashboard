# Registro de Supuestos

Cada vez que se use un supuesto provisional (por falta de dato Nivel A/B), se registra aquí.
Un supuesto no registrado es una violación metodológica.

| ID | Supuesto | Justificación | Sensibilidad | Consecuencia si es falso | Cómo validar | Estado |
|----|----------|---------------|--------------|--------------------------|--------------|--------|
| S-000 | *(ejemplo)* Se asume una tasa de retención X% entre sub-15 y sub-17 | No hay dato público consolidado | Alta: mueve el tamaño del embudo | Sobre/subestima la pérdida de talento | Convenio de datos con FMF/clubes | ABIERTO |

## Convenciones
- **Sensibilidad:** Alta / Media / Baja — cuánto cambian las conclusiones si el supuesto varía.
- **Estado:** `ABIERTO` (en uso) → `VALIDADO` (confirmado con dato) / `DESCARTADO`.
- Todo supuesto de sensibilidad **Alta** debe ser revisado por el red team (Fase 8).
